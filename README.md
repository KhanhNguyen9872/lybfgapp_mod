## 🌟 Introduction

**LybFrameGen Mod** is an unofficial modification of [lybxlpsv’s Frame Generation](https://lybxlpsv.com/framegen) for Android. This tool uses frame interpolation techniques to increase perceived motion smoothness, potentially doubling the FPS on supported devices.

## ✨ Key Features

-   **🚀 Frame Interpolation**: Boost apparent FPS for smoother gameplay and UI.
-   **🛠️ Magisk/KernelSU Support**: Systemless installation via root modules.
-   **🔓 Unofficial Mod**: Tweaked for better compatibility or specific features.

## 🚀 Installation Guide

**Requirement:** Root access (Magisk/KernelSU/SukiSU).

1.  **Download**: Get the APK and Module from the links above.
2.  **Install Module**: Flash the module in your root manager (Magisk/KSU).
3.  **Install APK**: Install the companion app.
4.  **Grant Root**: Open the "Frame Gen" app and grant root permissions.
5.  **Reboot**: Restart your device.
6.  **Activate**:
    -   Open the app, agree to terms.
    -   Go to **License** and click **Verify and Save** directly (no need to copy/paste any license code; it will be auto-filled offline).
    -   Wait for "License has been set" and "Valid" confirmation.
